# 数据模型说明

## 1. 设计原则

1. **一人一文件**：`data/emperors/{id}.yaml`，便于分批撰写与 Git 审阅  
2. **地点归一**：所有地图坐标只进 `data/places/`，人物只引用 `place_id`  
3. **稳定 id**：URL 与交叉引用都依赖 id，改名不改 id  
4. **构建时解析**：`[[other-id|显示名]]` 在构建期变成真实链接  

## 2. 帝王主数据（Emperor）

路径：`data/emperors/{id}.yaml`

```yaml
id: qin-shi-huang
tier: emperor                    # emperor | quasi | honorary
sort_key: "秦-001"               # 总览排序用

names:
  display: 秦始皇
  personal: 嬴政
  temple: null                   # 庙号，无则 null
  posthumous: 始皇帝             # 谥号/尊号（按史实填写）
  aliases: ["秦王政", "始皇帝"]

dynasty:
  id: qin
  label: 秦
  sequence: 1                    # 该政权第几位（工作序号）

reign:
  start: "-221"                  # 公历近似，允许字符串
  end: "-210"
  eras: ["始皇"]                 # 年号列表（秦制特殊可简化）

life:
  birth: "-259"
  death: "-210"
  birth_place_id: handan         # 可选
  death_place_id: shaqiu

summary: 完成华夏第一次大规模政治统一的秦帝国开创者。

tags:
  - 统一
  - 中央集权
  - 巡狩

portrait:
  primary: assets/portraits/qin-shi-huang/primary.png
  variants: []
  style_version: "v1-gongbi"
  appearance_basis: |
    《史记》未系统描写五官；此处依据时代服饰与史书气质描写作艺术想象。
  prompt_ref: tools/prompts/portrait-v1.md
  disclaimer: 艺术想象，非考古复原

bio:
  # 二选一：inline 或 file
  file: content/bios/qin-shi-huang.md
  # inline: |
  #   短文……可含 [[han-wu-di|汉武帝]] 式引用（跨时代仅作概念关联时慎用）

timeline:
  - year: "-230"
    date_note: 前230年
    title: 灭韩
    summary: 开启灭六国进程。
    place_id: xinzheng
    related_person_ids: []
    sources: ["史记·秦始皇本纪"]

relations:
  - type: successor
    target_id: qin-er-shi
    note: 二世皇帝
  - type: rival
    target_id: null
    note: 可先写 note，target 待补

routes:
  - group: 巡狩
    order: 1
    year: "-219"
    place_id: taishan
    event: 封禅泰山
  - group: 巡狩
    order: 2
    year: "-210"
    place_id: shaqiu
    event: 沙丘病逝

sources:
  - title: 史记·秦始皇本纪
    note: 主叙事框架
  - title: 资治通鉴
    note: 编年对照

meta:
  status: draft                  # draft | review | published
  confidence: medium             # low | medium | high
  last_reviewed: null
  inclusion_reason: 秦朝开国皇帝，正史本纪。
```

### 关系类型 `relations[].type`

| 值 | 含义 |
|----|------|
| `predecessor` | 前任 |
| `successor` | 后任 |
| `kinship` | 亲属 |
| `minister` | 权臣/重臣 |
| `rival` | 对手/交战方重要人物 |
| `related_emperor` | 其他相关帝王 |
| `other` | 其他 |

### 收录层级 `tier`

| 值 | UI |
|----|-----|
| `emperor` | 正式图鉴页 |
| `quasi` | 「准」角标 + 略旧纸色 |
| `honorary` | 默认隐藏，设置中可开 |

## 3. 地点（Place）

路径：`data/places/{id}.yaml`

```yaml
id: xianyang
names:
  historical: 咸阳
  modern: 陕西省咸阳市附近
coords:
  # 示意图坐标即可；precision 标明精度
  lng: 108.7
  lat: 34.3
  precision: approximate        # exact | approximate | schematic
map:
  region: 关中
notes: 秦都
```

## 5. 交叉引用语法

在 `bio` Markdown 中：

```markdown
其后汉室武功极盛，可参见 [[han-wu-di|汉武帝]]。
```

规则：

- 目标必须是已存在的 `emperors[].id`  
- 显示名可省略：`[[han-wu-di]]` → 用对方 `names.display`  
- 构建脚本生成 `links.json` 与坏链报告  

## 6. 索引产物（构建生成，勿手改）

```
data/generated/
  emperors.index.json    # 总览列表
  links.json             # 引用图
  validate-report.json   # 校验结果
```

## 7. 校验规则（MVP）

1. 所有 `id` 唯一、kebab-case  
2. `portrait.primary` 文件存在（published 状态强制）  
3. `timeline[].place_id` / `routes[].place_id` 必须存在于 places  
4. `relations[].target_id` 若非 null 必须存在  
5. bio 内 `[[id]]` 必须可解析  
6. `tier=quasi|honorary` 必须有非空 `inclusion_reason`
