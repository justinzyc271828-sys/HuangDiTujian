# 参考库建设指南：史书 · 地图 · 年表

> 目的：为《皇帝图鉴》搭一座**可回查、可引用、可分期扩充**的本地/在线参考库。  
> 原则：**权威底本 + 开放数据库 + 纸质工具书**三层并用；先服务首批 3 人，再按朝代扩张。  
> 相关决策（2026-08）：画像风格暂缓；启用收集进度；准帝王第一期预留入口；地图交互参考 `docs/references/ui-map-flow-reference.jpg`。

## 0. 你这张参考图在告诉我们什么（地图体验）

截图（明清「入仕流动」类可视化）对产品地图的可借鉴点：

| 元素 | 参考图里有什么 | 图鉴里怎么用 |
|------|----------------|--------------|
| 底图 | 浅色行政区轮廓，干净不抢线 | MVP 用简化中国轮廓/示意政区即可 |
| 弧线路径 | 起讫点之间的弯曲迁徙线 | 帝王：巡狩、亲征、迁都、蒙尘路线 |
| 图例 | 分色 = 类型；粗细 = 强度 | 分色 = 路线类型；粗细可表「重要程度」或次数 |
| 时间条 | 年代区间 + 步长 + 播放速度 | 年表 scrubber：按年高亮事件与路径 |
| 侧栏榜单 | Top 流入/流出 | 改为「关键地点 Top」或「事件列表」 |
| 缩放 | 百分比 + 重置 | 必须有 |
| 2D/3D | 可选 | **MVP 只做 2D**；3D 后期 |

**注意：** 参考图是「多人流量 OD 图」；我们做的是「**单人一生轨迹**」。交互壳可学，数据模型保持 `routes[]` + `places`，不要一上来做全国流量分析。

## 1. 参考库总体结构（建议在本地建）

可在仓库外建资料夹（体积大、版权杂），仓库内只放**索引与摘录**：

```
D:\Reference\HuangDiTujian-Ref\     # 建议仓库外
├── 01-史书全文与扫描\              # 电子书、下载、笔记
├── 02-工具书\                      # 纪年表、地名词典、书目
├── 03-地图与GIS\                   # 谭图扫描、CHGIS、自用 SVG
├── 04-人物与关系库\                # CBDB 导出、笔记
├── 05-通行通史与二手\              # 剑桥中国史、白寿彝等（对照用）
└── 06-本项目摘录\                  # 每人一张「史源卡」→ 再写入 data/

HuangDiTujian/docs/references/      # 仓库内：索引、截图、书目清单
HuangDiTujian/content/sources/      # 可选：每人 sources 笔记（无大段版权正文）
```

**版权红线：**  
参考库可以「自用收藏」通行本与公开数据；写入产品正文时用**自己的综述 + 卷目出处**，避免整卷复制现代点校本/今译。

## 2. 权威史书史料：去哪里找

### 2.1 核心层级（做图鉴够用）

| 层级 | 类型 | 用途 | 代表 |
|------|------|------|------|
| **A 正史本纪** | 二十四史 + 清史稿 的「本纪」 | 帝王主叙事、在位大事 | 《史记》《汉书》…《明史》《清史稿》 |
| **B 编年** | 通鉴系统 | 年表排比、年月校正 | 《资治通鉴》《续资治通鉴》《明通鉴》 |
| **C 实录/起居** | 明清更详 | 细事、日期 | 《明实录》《清实录》（体量大，按需查） |
| **D 会要/政书** | 制度与年表辅助 | 年号、职官、都城 | 《唐会要》《西汉会要》《文献通考》等 |
| **E 地理专书** | 地名与政区 | 地点库、路线定点 | 《水经注》《元和郡县图志》《读史方舆纪要》《嘉庆重修一统志》 |
| **F 二手通史** | 现代学术共识 | 避免野史跑偏 | 《剑桥中国史》、白寿彝《中国通史》、各断代史 |

**首批 3 人最小书单（建议立刻备齐）：**

| 人物 | 必读 A | 必读 B | 地理/辅助 |
|------|--------|--------|-----------|
| 秦始皇 | 《史记·秦始皇本纪》 | 《通鉴》秦纪相关卷 | 《中国历史地图集》秦图；关中/山东地名 |
| 汉武帝 | 《史记·孝武本纪》《汉书·武帝纪》 | 《通鉴》汉纪 | 北疆、河西、南越相关图幅 |
| 唐太宗 | 《旧唐书·太宗纪》《新唐书·太宗纪》 | 《通鉴》唐纪 | 关中、河北、突厥方向图幅 |

> 准帝王入口预留后，名单未定时不必先囤全史；有总目录与检索入口即可。

### 2.2 在线全文与检索（优先）

| 资源 | 地址/获取 | 适合 | 注意 |
|------|-----------|------|------|
| **中国哲学书电子化计划 ctext** | https://ctext.org/zhs | 《史记》等先秦两汉极强；亦有武英殿二十四史扫描 | 勿用爬虫狂下；适合人工检索与对照 |
| **国学/古籍站点** | 如国学导航等公开站 | 快速翻卷 | 版本未必精良，重要句回查点校本 |
| **大学图书馆数据库** | 爱如生、鼎秀、瀚堂、文渊阁四库… | 善本、全文、影印 | 需读者证/校园网；质量高 |
| **国家图书馆/省级馆** | 读者卡 + 数字资源 | 实录、方志、舆图 | 线下+线上结合 |
| **中华书局点校本** | 纸书或正版电子 | **写作时的权威底本** | 引用卷名、篇名即可 |

**实操建议：**

1. 每人建一张「史源卡」（见 §6 模板）  
2. 本纪通读一遍 → 标 15–30 个「可上年表」事件  
3. 用《通鉴》对年月  
4. 争议处标 `confidence: low` 并写两说  

### 2.3 人物关系与任官（扩展用）

| 资源 | 说明 |
|------|------|
| **中国历代人物传记资料库 CBDB** | https://chinesecbdb.hsites.harvard.edu/ 哈佛–中研院–北大合作；结构化人物、亲属、地址、任官；可下载研究用数据 |
| 宋元明清人物传记索引类工具书 | 补 CBDB 之前时代或交叉验证 |

帝王「本纪」仍以正史为准；CBDB 更适合权臣、亲属网、迁转地——关联表很好用。

### 2.4 纸质「桌面三件套」（强烈建议购置或借阅）

1. **中华书局点校本** 相关本纪（至少史汉旧新唐）  
2. **《资治通鉴》**（中华书局）+ 可选胡注本  
3. **方诗铭《中国历史纪年表》** 或万国鼎/其它通行纪年表  
4. **谭其骧主编《中国历史地图集》**（八册）或《简明中国历史地图集》  

这四样能覆盖 80% 的「写一个皇帝页」需求。

## 3. 古代地图与政区：去哪里找

### 3.1 权威图集（读图、定点）

| 资源 | 用途 | 获取 |
|------|------|------|
| **谭其骧《中国历史地图集》**（谭图） | 历代标准年代政区、都城、山川；业界默认权威 | 纸质（地图出版社）；部分网站有浏览图（版权注意）；复旦已启动修订与未来公开平台计划，长期可跟 |
| **《简明中国历史地图集》** | 轻量随身 | 纸质，入门够用 |
| **杨守敬《历代舆地图》** | 传统沿革 | 研究向，非第一优先 |
| 各朝专图、行省图、边镇图 | 细路线 | 国图舆图部、省图、博物馆图录 |

**用法：** 不要求把谭图整本扫进产品。做法是：  
事件出现地名 → 查谭图该朝图幅 → 对照今地 → 写入 `data/places` 的 `modern` + 示意坐标。

### 3.2 开放 GIS / 数字人文数据（做交互地图）

| 资源 | 地址 | 能给你什么 | 许可注意 |
|------|------|------------|----------|
| **CHGIS（中国历史地理信息系统）** | https://chgis.fas.harvard.edu/ 数据：Harvard Dataverse chgis_v6 | 历史地名、政区时间序列、1820/1911 等切片；学术研究常用 | 多为**学术免费、限制商用再分发**——产品商用前读许可证 |
| **复旦等历史地理信息平台/相关成果** | 检索「中国历史地理信息平台」「谭图数字化」 | 政区、古旧地图服务（视开放程度） | 以各平台 TOS 为准 |
| **上海图书馆开放数据** | https://opendata.library.sh.cn/ 、纪年 https://data.library.sh.cn/dynasty/main | 历史纪年表等开放数据 | 适合年号/公元换算辅助 |
| **Natural Earth / 国界示意数据** | 现代底图轮廓 | 只做「示意底图」海岸线 | 历史疆域勿直接当古界 |

**MVP 地图策略（与参考 UI 对齐）：**

1. 自绘或找**可自由使用**的简化中国轮廓 SVG  
2. 地点用 CHGIS/谭图**人工定点**进 `places`（不必整库导入）  
3. 弧线用前端画（像参考图的 bezier），数据仍是有序 `routes`  
4. 全库自动贴合「历代真实疆界图层」放到 M3+  

### 3.3 古旧地图影像

- 中国国家图书馆「数字方志/舆图」类资源  
- 哈佛燕京、斯坦福等海外图书馆中国地图数字化项目（检索 “Chinese rare maps”）  
- 仅作**视觉参考与考订**，不要直接当无版权素材贴进 App

## 4. 年表与纪年：去哪里找

| 需求 | 推荐 |
|------|------|
| 年号 ↔ 公元 | 方诗铭《中国历史纪年表》；上图「中国历史纪年表」开放数据 |
| 编年叙事 | 《资治通鉴》及续作；正史本纪 |
| 大事速查 | 各出版社《中国历史大事年表》类工具书（二手，需回查） |
| 帝王在位起讫 | 正史本纪 + 通行年表交叉；并存异说时在 YAML 备注 |
| 出土与考古校正 | 断代考古报告、学术综述（晚期精修用） |

**写进产品的年表标准：**

- 优先：公历年（可用 `" -141"` 字符串）+ `date_note` 写「武帝元光元年」之类  
- 每条尽量能指回「哪本书哪一篇」  
- 同一年多事：拆多条，勿揉成一团

## 9. 常见坑

1. **维基当唯一出处** — 可作索引，句子必须回查本纪/通鉴。  
2. **戏说、网络野史写进主文** — 最多进「传说」折叠，默认关闭。  
3. **把现代省界当古界** — 参考图是示意行政单元；古路线用点+弧即可，界线后期再上。  
4. **整库导入 CHGIS** — MVP 过重；人工维护几十个 `places` 更稳。  
5. **商用忽略许可** — CHGIS 等学术数据商用前读 license；谭图影像勿直接再发布。
