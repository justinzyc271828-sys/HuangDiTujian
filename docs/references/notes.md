# UI / 体验参考纪要

## 参考来源

## 地图参考结论（已对齐产品）

最想复刻：

1. **弧线迁徙/路径**（点与点之间的弯曲连线，而非生硬折线）  
2. **图例分色**（不同类型路径不同颜色）+ 可选线粗表重要度  
3. **时间维度控件**（年代区间 / 步长 / 播放）与地图联动  
4. **左侧或浮层列表**（参考图是 Top 流入流出；我们改为关键地点 / 事件列表）  
5. **缩放 + 重置**；MVP **只做 2D**

明确差异：

- 参考图 = 多人 OD 流量；本产品 = **单帝一生轨迹**  
- 不需要第一期就上真实历史政区填色全图层
