## 已知问题（写史料卡时注意）

1. **繁体**为主 → 与产品简体 YAML 混用时统一转写即可  
2. **卷序打乱**（汉、唐尤甚）→ 用编辑器搜索 `## 卷006` / `### 武帝`，不要线性通读文件  
3. **wikitable 残留** → 表志麻烦，本纪列传正文一般干净  
4. **标题不叫「某某本纪」** → 史记用 `### 始皇帝`，汉书用 `### 武帝`，旧唐用 `### 太宗上`  
5. **维基底本 ≠ 点校本** → 关键数字、异文以 `HuangDiTujian-Ref` 内点校本 PDF 抽查  
6. **无《通鉴》md** → 编年钉年仍用通鉴 epub 或另抓
