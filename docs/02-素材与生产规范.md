# 素材与生产规范

## 1. 文风

| 模块 | 风格 | 长度建议 |
|------|------|----------|
| `summary` | 一句史识，避免空洞赞美 | ≤ 40 字 |
| 主要事迹 | 文言白话夹杂、可读、有判断 | 800–2000 字 |
| 年表 `title` | 动词性短标题 | ≤ 12 字 |
| 年表 `summary` | 事实 + 一句影响 | 1–3 句 |
| 标签 `tags` | 名词性历史标签 | 3–8 个 |

禁忌：

- 无出处的离奇野史当主叙事  
- 现代网络梗堆砌（可用一点点，不作主文）  
- 对仍在争议的史事下绝对断语（用「一说」「史载」）  

## 2. 画像生产

### 2.1 Style Bible（v1 建议）

在批量出图前，先锁定 **3 张锚点图**（不同年龄/服饰朝代样本），写入：

- `assets/style-bible/v1/README.md`  
- 锚点图本身  

统一约定（草案，可改）：

- 半身或七分身，面部清晰  
- 背景：哑光宣纸肌理 + 淡墨山水或留白，不抢脸  
- 服饰：大时代正确（袖宽、冠式、甲胄层级）宁可简化，不要现代戏服感  
- 光：侧顶柔光，少霓虹  
- 画幅：统一 3:4 竖图，导出 1536×2048 或同比例  

### 2.2 单人流程

1. 填写 `portrait.appearance_basis`（史书/画像传统依据）  
2. 用 `tools/prompts/portrait-v1.md` 套模板生成 prompt  
3. 出 4–8 张 → 选 1 主图  
4. 轻量后处理：统一色温/边距  
5. 落入 `assets/portraits/{id}/primary.png`  
6. 缩略图可由构建脚本自动裁切  

### 2.3 必须出现的免责声明

页面脚注固定文案：

> 本画像依据公开史籍中的气质、时代服饰与艺术传统生成，属于历史想象，不作为真实相貌复原。

## 3. 地图与地点

### 3.1 底图

- 优先 **一张简化 SVG 总览图**（海岸 + 黄河长江示意 + 可投影坐标）  
- 不在 MVP 做「每朝边界动态图层」（V2 再考虑）  

### 3.2 路线分组命名

建议固定分组名，便于配色：

| group | 含义 | 线型建议 |
|-------|------|----------|
| 迁都 | 都城转移 | 粗实线 |
| 巡狩 | 巡行、封禅 | 细实线 |
| 亲征 | 御驾征伐 | 粗虚线 |
| 流徙 | 流放、蒙尘 | 点线 |
| 其他 | 自定义 | 灰 |

### 3.3 精度诚实

`coords.precision`:

- `schematic`：只为好看摆点  
- `approximate`：今地附近  
- `exact`：较少使用  

UI 可对 approximate/schematic 显示「示意」。

## 4. UI 参考采集

请将 B 站等参考的 **本地截图** 放入：

```
docs/references/
  ui-map-sidebar.png
  ui-gallery.png
  notes.md
```

`notes.md` 写清：你喜欢参考片里的哪 3 点（动效/材质/信息密度/地图联动…）。

因外网抓取 B 站常被风控，**以你本地观感纪要为准**。

## 5. 命名规范

| 对象 | 规则 | 例 |
|------|------|-----|
| 人物 id | 小写 kebab，拼音通行 | `tang-tai-zong` |
| 地点 id | 小写 kebab | `chang-an` |
| 画像目录 | 与 id 相同 | `assets/portraits/tang-tai-zong/` |
| 王朝 id | 短拼音 | `tang`, `n-song` |

## 6. 质量门禁（合入 published 前）

- [ ] summary / bio / 至少 5 条 timeline  
- [ ] 至少 2 个 relations（可含前后任）  
- [ ] 至少 3 个 route 点（若一生少迁徙可写都城相关）  
- [ ] 主画像存在且过 Style Bible  
- [ ] 校验脚本无 error  
- [ ] sources 至少 1 条
