# 参考库索引总表

由 `tools/build_ref_indexes.py` 生成。写史料卡时：

1. 默认用 **简体** 语料（`二十四史-简体`、`资治通鉴-简体`）
2. 打开下方对应「目录」用搜索跳卷
3. 摘句进 `content/sources/{id}/证据/` 或 `摘录/`
4. 繁体目录仅作对照
