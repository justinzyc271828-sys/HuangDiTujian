# 静态主画面版式 · 对照《文豪图鉴》

> 参考帧：B 站「中国历代文豪图鉴」类成片（井中贺知章那格）  
> 本项目对应：**皇帝图鉴 video-01 · 单人 Key Art（静帧）**  
> 出图原则：**画面本体用英文提示词生成；叠字/雷达用中文后期叠**（与参考一致）

---

## 1. 参考帧拆解（你贴的那张）

| 区域 | 文豪图鉴 | 皇帝图鉴映射 |
|------|----------|--------------|
| 全幅插画 | 人物 + 代表事件场景（井中醉卧） | 人物 + **一个**代表事件 + 相关背景 |
| 左下 | 圆环六维雷达（白线 + 数字） | 文言六维：武功·文治·韬略·国祚·后效·月旦 |
| 右上 | `[代表作]` + 作品名 | `[代表事]` + 事件名 **不加书名号**（皇帝不是诗集） |
| 右下 | `[绰号]` + **人名** | `[四字号]` + **本名在上**，通行称号在下 |
| 整体 | 暗角、景深、中心人物、氛围统一 | 同 |
| 生成图内 | 基本无 UI 字（字是后期） | **英文 prompt 禁止写中文 UI** |

### 视觉语法（必须学到的）

1. **事件即场景**：不是证件照，是「他被钉在这件事里」（井 = 狂客）。  
2. **道具讲故事**：酒瓮、井壁、衣袍颜色都在帮腔。  
3. **构图让位 UI**：左下留暗部/空区给雷达；右缘留字空。  
4. **风格**：厚涂/半动画史诗插画，电影光，不是写实照片，不是 Q 版。

## 2. 本项目固定画幅

| 项 | 建议 |
|----|------|
| 成片画幅 | **16:9**（B 站横屏主用）；另可出 9:16 裁切版 |
| 生成分辨率 | 优先 1920×1080 或工具支持的 16:9 高清 |
| 安全区 | 四周 5%；左下 28%×38% 留给雷达；右侧 22% 留给标题字 |

```
┌──────────────────────────────────────────────────────────┐
│  (可选顶栏：系列名，后期叠)                                 │
│                                                          │
│   ┌─────────┐              主场景插画（人物+事件+环境）      │
│   │ 雷达区  │                          ┌ 代表事 标题     │
│   │ (后期)  │                          │                 │
│   └─────────┘                          └ 四字号+姓名     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. 分层生产（推荐）

| 层 | 内容 | 怎么做 |
|----|------|--------|
| **A 底板** | 纯插画：人+事件+背景 | Image 英文 prompt，**no text no UI** |
| **B 雷达** | 六维环图 + 分数 | 程序/AE/前端按 `video20.json` 画 |
| **C 中文叠字** | `[代表事]` `[四字号]` 姓名 | 字体后期；字稿见每人卡 |
| **D 系列壳** | 顶栏、进度条、B 站框 | 成片时再加 |

**不要**让 Image 直接画雷达和汉字——难稳、难改分。

## 4. 英文 Prompt 通用前缀 / 后缀

### PREFIX（每条前加）

```text
Chinese historical epic character atlas key art, cinematic illustration, semi-realistic anime painterly style, dramatic lighting, rich atmosphere, full scene storytelling composition, one Chinese emperor as the sole main character, signature historical moment frozen in one frame, highly detailed environment that explains the event, 16:9 widescreen,
```

### SUFFIX（每条后加）

```text
leave darker empty space in the lower-left third for a future radar UI overlay, leave clean darker margin on the right side for Chinese title text, no readable text, no letters, no Chinese characters, no UI, no watermark, no logo, no modern objects, no photorealistic selfie look, masterpiece composition
```

### NEGATIVE（若工具支持）

```text
text, letters, Chinese characters, English words, watermark, logo, UI, radar chart, HUD, QR code, modern clothing, guns, cars, neon cyberpunk, chibi, deformed hands, extra limbs, duplicate faces, lowres, blurry
```

## 5. 中文叠字字段模板（后期）

**硬规则：**

1. 主名用**本人姓名**（`personal`），不要只用庙号/通行称号当主名。  
2. 可「本名 + 称号」两行，**本名在上**（例：嬴政 / 秦始皇）。  
3. 代表事**禁止**书名号 `《》`（文豪出作品才像；皇帝出事很怪）。

```
[代表事]
{事件短句1}
{事件短句2可选}

[四字号]
{personal_name}
{display_title}
```

例：

```
[代表事]
前221称帝
书同文·车同轨

[一统六合]
嬴政
秦始皇
```

六维标签固定：

| 轴 | 中文 |
|----|------|
| wugong | 武功 |
| wenzhi | 文治 |
| taolue | 韬略 |
| guozuo | 国祚 |
| houxiao | 后效 |
| yuedan | 月旦 |

分数只来自 `data/catalog/video20.json`，勿手改分叉。
